Adicionar efeito de troca de textos entre idiomas quando usuário troca a página de idioma.

Implementar efeito mediante a troca de idioma na página. O efeito se trata de que, quando o idioma da página é trocado, ao invés dos textos serem trocados imediatamente, o texto atual dá fade out e o substituto aparece, letra por letra, preenchendo os espaços. Esse efeito de aparecimento quero esclarecer bem como funciona para ficarmos entendidos: Da esquerda pra direita, letra por letra, elas dão fade in. Isso deve ocorrer com todos os textos da página que são trocados quando o idioma é trocado. Esse fade in deve durar o mesmo tempo para todos as palavras, indiferente do tamanho. O fade in deve ser feito pra cada palavra individualmente, ao invés de ser feito para o texto, de começo a fim. Antes de implementar, vamos conversar sobre qual será a complexidade do algoritmo que executará esse efeito e se isso vai pesar demais no processamento, pois se for pesar muito, re-veremos.
